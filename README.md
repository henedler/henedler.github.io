# henedler.github.io

Personal research page of Henrik W. Edler.

## Publish on GitHub Pages
1. Create a public repository named `henedler.github.io`.
2. Upload `index.html`, `.nojekyll`, the `img/` folder and the `cv/` folder.
3. Put the current CV at `cv/Edler_CV.pdf`.
4. The site goes live at https://henedler.github.io within a minute or two
   (Settings -> Pages shows the status).

## Updating
Edit `index.html` directly. Replace `cv/Edler_CV.pdf` when the CV changes.
